# Ronde 2 — Review (besluiten)

Unaniem **GO** op Prototype 1 "KUD: KANALEN". Knopen doorgehakt:

| Spanning | Besluit |
|---|---|
| Poorten per kaart | **2–3** (variatie, leesbaar bord) — unaniem |
| Max 2 open per kleur | **Behouden** — unaniem; Marcus: alleen blokkeren als het echt jouw probleem is |
| Prullenbak-filter | **Behouden, begrensd**: alleen als je écht niet kunt leggen, max 1/beurt; run van 3+ = 1 gratis weggooi |
| 2D-groei begrenzen | **Max 5 schermen breed, onbeperkt hoog** (Sander; YouTube-zijbalk-gevoel) |
| Componenten/kleurenblind | Poorten als **smalle edge-noppen + symbool + reliëf** (Priya); deluxe = magneetkabels |
| Authenticiteit | **Flavor-tekst per kaart** + KUD-actienamen (Sander) |

**Gerichte verbeteringen:**
- Lena: gridframe/randmarkering; poort-oriëntatie asymmetrisch (stuurt groei).
- Marcus: KNIP als **interrupt** (vóór tegenstanders run); run 3+ = gratis weggooi.
- Priya: poort = reliëfring + symbool (klik zonder magneet in basis); poorten op 5 mm-rand, still 90%.
- Sander: 4 energieën aanscherpen met flavor ("Konijntje — nog steeds aan het rennen"); ARCHIEF→**HERUITGAVE**, HERSCHRIJVEN→**MONTAGEFOUT**.

**Playtest-risico's:** Pilon-wild kan de "max 2 open"-rem omzeilen (test aantal); kan één lange run de beurt domineren?; reliëf-nop productie-tolerantie; wordt de Reprise-lus überhaupt nagestreefd of voelt-ie "te netjes/te on-KUD"?
